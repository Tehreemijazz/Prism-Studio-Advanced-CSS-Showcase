# Prism Studio – Advanced CSS Showcase

A modern, visually engaging product showcase and creative portfolio website built using HTML, CSS, and Vanilla JavaScript. This project demonstrates advanced CSS animations, 3D transformations, gradients, visual effects, scroll interactions, and responsive web design.

## Project Overview

Prism Studio is an interactive website designed to explore modern CSS capabilities and create visually impressive user experiences without relying on heavy external libraries.

The project combines animated backgrounds, interactive 3D product cards, glassmorphism, advanced gradients, parallax effects, portfolio filtering, lightboxes, and responsive navigation.

## Features

### 1. Animated Hero Section
- Full-screen hero layout.
- Animated conic and radial gradient backgrounds.
- Floating decorative elements.
- Animated heading with staggered entrance effects.
- Gradient text animations.
- Interactive call-to-action buttons.
- CSS-based 3D illustration.

### 2. Interactive 3D Product Cards
- Three featured product cards.
- CSS perspective and 3D transformations.
- Interactive mouse-based card tilting.
- Rotation, scaling, and translation effects.
- Smooth hover transitions.
- Different visual depths using `translateZ()`.

### 3. Advanced CSS Visual Effects
- Glassmorphism using `backdrop-filter`.
- Gradient text using `background-clip`.
- Custom polygon shapes using `clip-path`.
- CSS masking with radial gradients.
- Blend modes using `mix-blend-mode`.
- Animated gradient borders using `@property`.
- Layered backgrounds and gradient combinations.

### 4. Scroll Interactions
- Scroll progress indicator.
- CSS scroll-driven animations.
- Scroll-based reveal effects.
- Parallax-style visual effects.
- Intersection Observer fallback for unsupported browsers.

### 5. Creative Portfolio Gallery
- Six creative project cards.
- Project categories: Branding, Web, and Motion.
- Interactive category filtering.
- Hover-based image and caption animations.
- View Transitions API for smooth filtering transitions.

### 6. Interactive Components
- Responsive navigation menu.
- Animated mobile navigation.
- Dropdown navigation menu.
- Interactive product cards.
- Portfolio image lightbox.
- Contact modal using HTML `<dialog>`.
- Animated FAQ accordion using `<details>` and `<summary>`.
- Keyboard-accessible controls.

### 7. Accessibility and Performance
- `prefers-reduced-motion` support.
- Visible keyboard focus states.
- Semantic HTML elements.
- Smooth CSS transitions.
- Transform and opacity-based animations.
- Conditional feature support using `@supports`.
- Graceful fallbacks for unsupported browser features.

## Technologies Used

- HTML5 – Semantic structure and interactive elements.
- CSS3 – Advanced styling, animations, gradients, transformations, masking, and visual effects.
- Vanilla JavaScript – Interactive functionality and event handling.
- CSS Scroll-Driven Animations – Scroll-based visual effects.
- View Transitions API – Smooth transitions between gallery states.
- Intersection Observer API – Fallback scroll reveal animations.

## 📚 Advanced CSS Concepts Practiced

| Concept | CSS Features |
| Keyframe Animations | `@keyframes`, delays, timing functions |
| Transitions | `transition`, `transition-timing-function` |
| 2D Transformations | `rotate()`, `scale()`, `translate()` |
| 3D Transformations | `perspective`, `rotateX()`, `rotateY()` |
| 3D Card Effects | `transform-style: preserve-3d` |
| Gradients | Linear, radial, and conic gradients |
| Gradient Text | `background-clip: text` |
| Clipping | `clip-path: polygon()` |
| Masking | `mask`, `-webkit-mask` |
| Blend Modes | `mix-blend-mode`, `background-blend-mode` |
| Glassmorphism | `backdrop-filter` |
| Advanced Selectors | `:has()`, `:focus-within`, `:focus-visible` |
| Scroll Animations | `animation-timeline`, `view()` |
| Accessibility | `prefers-reduced-motion` |
| Browser Compatibility | `@supports` |
